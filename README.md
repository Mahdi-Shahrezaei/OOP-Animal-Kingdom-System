A robust C++ console application that models the animal kingdom using Object-Oriented Programming principles. This project serves as an academic demonstration of class inheritance, polymorphism, and file-based data persistence.

## 🏗️ Project Architecture
The system is built on a structured class hierarchy, allowing for clean categorization of animal species.

- **Base Class:** `Animals_class`
- **Sub-classes:** Including `vertebrate`, `in_vertebrate`, `Mollusca`, and others.
- **Features:**
  - **Inheritance:** Efficient code reuse and hierarchical categorization.
  - **File I/O:** Custom `savefile()` and `osave()` methods for persistent storage using `nlist.txt`.
  - **Dynamic Input/Output:** User-friendly console interface for managing animal details.

## 🚀 Key Features
- **Scalable Design:** Easily add new species by creating new derived classes.
- **Data Persistence:** Save your animal data to local files and retrieve them.
- **OOP Demonstrator:** Clean, documented code structure suitable for educational purposes.
